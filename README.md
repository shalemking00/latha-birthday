# Birthday Surprise React App 💕

## Run locally
```bash
npm install
npm run dev
```

## Replace the temporary photos
Open `src/main.jsx` and find the `photo-grid` section. Replace the six Unsplash image URLs with your own image URLs.

For local photos, put them inside `public/photos/` and use paths such as `/photos/her1.jpg`.

## Music
Put a royalty-free MP3 at `public/birthday-music.mp3`.

## GitHub Pages
Push the project to the `main` branch. The included `.github/workflows/deploy.yml` deploys it using GitHub Pages Actions.
